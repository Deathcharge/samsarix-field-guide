03 / Read the labels correctly

A catalog, not a certification

+

What is reviewed here

Each repository is publicly reachable, its description is deliberately cautious, and its route was checked against the public profile and the available sibling checkout.

−

What is not certified

Package publication, compatibility, security, maintenance level, licensing, deployment, and production readiness must be verified in the destination repository.

◇

Why some URLs still say Helix

Samsarix is the current company brand. Existing Helix-era repository names remain visible as stable addresses and project history; private flagship work is not treated as a public route.

04 / Lightweight by design

No account. No tracking. No live dependency graph.

The catalog ships as static files and makes no background network requests. It stores nothing in your browser. The only network activity after load happens when you choose an outbound link.

That keeps the guide fast, cheap to host, easy to audit, and useful even if another Samsarix project is unavailable.
