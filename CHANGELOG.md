# Changelog

All notable changes to Samsarix Field Guide are documented in this file. The project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html) for its public release history.

## [Unreleased]

## [1.0.0] - 2026-08-11

### Added

- An evidence-backed catalog of all 31 reviewed public Samsarix and Helix-era repositories.
- An eight-outcome Decision Workbench with six explicit operating constraints.
- Transparent recommendations, three-project comparisons, shareable URL state, and copyable pilot plans.
- Product boundaries, competitive positioning, contribution guidance, security reporting, structured pilot-result and catalog-correction issue forms, and live inventory/route audits.
- Machine-readable citation metadata for crediting Samsarix LLC.

### Changed

- Replaced legacy Helix company branding with Samsarix, Samsarix LLC, and the current contact and support addresses while retaining literal historical repository coordinates.
- Rebuilt the repository as a dependency-free static product with deterministic checks and least-privilege GitHub Pages deployment.
- Moved keyboard focus to the main region when a visitor activates a skip link.

### Security

- Replaced the mismatched legacy license with MPL-2.0, a Samsarix LLC copyright notice, and a separate trademark policy.
- Added a restrictive browser Content Security Policy, privacy-preserving referrer behavior, safe DOM rendering, secret scanning, push protection, pinned GitHub Actions revisions, and weekly action maintenance through Dependabot.
